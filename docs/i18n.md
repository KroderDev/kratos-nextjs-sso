# Internationalization (i18n) Guide

This application features an automated, zero-dependency internationalization system with full Spanish (`es`) language support alongside English (`en`).

## Language Resolution

Language selection is **100% automated** and operates without requiring a visible UI language switcher. The active locale is determined in the following order:

1. **URL Parameter**: Explicit `?lang=es` or `?lang=en` override.
2. **Cookie**: `NEXT_LOCALE` cookie preference.
3. **HTTP Header**: `Accept-Language` header analyzed on the server (e.g., `es-ES`, `es-MX`, `es-US`, `es`).
4. **Browser Settings**: Client-side `navigator.language` fallback via React `useSyncExternalStore`.
5. **Default**: Fallback to English (`en`).

## Adding a New Language

The i18n architecture uses a **centralized locale registry** in [`lib/i18n/locales/index.ts`](../lib/i18n/locales/index.ts). Adding a new language (e.g., French `fr`) requires only two simple steps:

### 1. Create the Locale Dictionary
Create `lib/i18n/locales/fr.ts`:

```ts
import type { TranslationKeys } from "./en";

export const fr: TranslationKeys = {
  common: { /* ... */ },
  home: { /* ... */ },
  auth: { /* ... */ },
  dashboard: { /* ... */ },
  ory: { /* ... */ },
};
```

> **Strict Type Enforcement**: `TranslationKeys` enforces 100% key completeness. Any missing key will trigger a TypeScript compilation error.

### 2. Export in the Locale Registry
Update `lib/i18n/locales/index.ts`:

```ts
import { fr } from "./fr";

export const dictionaries = {
  en,
  es,
  fr, // Registered automatically
} as const;
```

Once exported in the registry:
- TypeScript auto-infers `fr` as a valid `Locale`.
- The `Accept-Language` header parser automatically recognizes `fr-FR` / `fr` headers.
- The automated test suite (`pnpm test`) automatically includes `fr` in its key-parity health audit.

## Ory Kratos Form & Message Localization

Ory Kratos API backends emit form nodes (`UiNode`) and messages (`UiText`) in English by default.

The application automatically translates Ory Kratos form field labels, action buttons, placeholders, and validation error messages into the active locale via the text translation mapping in [`lib/ory/flow.ts`](../lib/ory/flow.ts).

## Validation & Audit

Run the test suite to verify key parity across all registered locale dictionaries:

```bash
pnpm test
```
